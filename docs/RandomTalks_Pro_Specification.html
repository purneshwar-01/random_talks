04. ACID Matchmaking & WebRTC Signaling Protocol

Signaling Sequence & State Handshake
Matchmaking Algorithmic Guarantees
  • Dual-Condition Mutual Filter: Candidate A is selected for Candidate B if and only if (A.gender == B.genderFilter || B.genderFilter == 'Any') AND (B.gender == A.genderFilter || A.genderFilter == 'Any').
  • Anti-Griefing Blocklist Enforcement: The Firestore transaction queries the caller's private /blocks/{uid}/blockedUsers index before committing, completely discarding matched candidates who have blocked or been blocked.
  • Stale Entry Eviction (Heartbeat Protection): Queue candidates whose joinedAt timestamp exceeds 120 seconds are automatically evicted during transaction scans to purge dead browser tabs.

07. Security, Trust & Threat Mitigation Matrix

Threat Vectors & Countermeasures
  • Client-Side Race Conditions: Countered by Firestore runTransaction which rolls back if a candidate's status flips during matching.
  • Underage Participation: Explicit legal confirmation checkbox required at profile creation. Under-18 accounts are rejected at client validation and blocked in firestore rules.
  • Zero-Vendor Privacy & Secret Isolation: Direct browser-to-browser media streams are encrypted end-to-end via DTLS-SRTP. No third-party media servers (ZegoCloud/Agora) exist in the data path. Client authentication is strictly managed via Firebase Auth tokens.
  • P2P Media Privacy: Direct WebRTC streams route peer-to-peer over DTLS-SRTP encryption; no intermediate video recording or cloud server interception occurs.
Production Deployment Checklist
  • Frontend: React 18, Vite 5, Tailwind CSS, Lucide React icons.
  • Backend Infrastructure: 100% Serverless Firebase Authentication and Cloud Firestore (Zero server maintenance costs).
  • Infrastructure: Firebase Authentication (Email/Password), Cloud Firestore.
  • Turn / ICE: Google Public STUN Cluster (5 geographically distributed endpoints).
  • AI Gateway: Generative Language API endpoint (Gemini 1.5 Flash).
